# อะไหล่ WPS1 (PWA + Google Sheet)

เว็บแอปจัดการอะไหล่บนมือถือ แทน AppSheet ใช้ Google Sheet `Database_Spareparts` และรูปในโฟลเดอร์
`DATA_Part_Images` / `Location_Images` ชุดเดิม ไม่ต้องย้ายข้อมูล QR เดิมบนอะไหล่สแกนได้ทันที

## ส่วนประกอบ

| ไฟล์ | อยู่ที่ไหน | หน้าที่ |
|---|---|---|
| Code.gs | Apps Script ของ Google Sheet | API อ่าน/เขียนข้อมูล |
| ไฟล์ที่เหลือทั้งหมด | GitHub Pages | หน้าแอปบนมือถือ |

## แอปทำอะไรได้

- **อะไหล่**: ค้นหา กรองของที่หมดคลัง หรือที่ยังไม่ตรวจปีงบนี้ ดูรายละเอียด รูป QR และประวัติการเบิก
  แก้ไขข้อมูล เพิ่มอะไหล่ใหม่ ถ่ายรูปใหม่ และกด "ตรวจแล้ว ปีงบ …" (เขียนลงคอลัมน์ ตรวจประจำปีงบ)
- **ตำแหน่ง**: จัดกลุ่มตามคอลัมน์ Rack พร้อมรูปชั้นวาง แตะตำแหน่งเพื่อดูอะไหล่ที่เก็บอยู่
- **ใบเบิก**: สร้างใบเบิก (เลขที่รันต่อให้อัตโนมัติ แก้เองได้) เลือกอะไหล่จากรายการหรือสแกน QR
  บันทึกเป็น "ร่าง" ก่อน แล้วกด **อนุมัติและตัดคลัง** แอปจะหักจำนวนใน DATA_Part ให้ และล็อกใบเบิกไม่ให้แก้
  ถ้าของในคลังไม่พอ แอปจะไม่ให้อนุมัติ
- **สแกน**: ปุ่มกลางแถบล่าง สแกน QR บนอะไหล่แล้วเปิดรายละเอียดทันที

## สิ่งที่แอปเขียนลง Google Sheet

- `DATA_Part`: แก้ค่าตามที่แก้ในแอป และใส่เวลาในคอลัมน์ Update ทุกครั้ง
- `Request_doc`, `Request_part`: ใบเบิกและรายการ (เพิ่มคอลัมน์ `ผู้บันทึก` ให้ใน Request_doc)
- ชีทใหม่ `StockLog`: ประวัติทุกครั้งที่จำนวนเปลี่ยน (เบิก แก้จำนวน เพิ่มใหม่) ว่าใคร เมื่อไร ก่อน/หลังเท่าไร
- รูปใหม่บันทึกในโฟลเดอร์ `DATA_Part_Images` ชื่อแบบเดียวกับ AppSheet รูปเก่าไม่ถูกลบ

## ขั้นที่ 1: ตั้งค่า Apps Script

1. เปิด Google Sheet `Database_Spareparts` → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดที่มีอยู่ วางเนื้อหา `Code.gs` ทั้งหมด → บันทึก
3. ไอคอนเฟือง **Project Settings** → **Script properties** → Add
   - Property: `TEAM_KEY`
   - Value: รหัสทีมที่จะแจกให้คนใช้งาน (ตั้งให้เดายาก)
4. กลับหน้าโค้ด เลือกฟังก์ชัน **testSetup** → **Run** → อนุญาตสิทธิ์
   (ถ้าขึ้น "Google hasn't verified this app" กด Advanced → Go to … (unsafe) เพราะเป็นสคริปต์ของเราเอง)
   ผลที่ควรได้ใน Execution log: `อะไหล่ 130 รายการ (มีรูป 123), ตำแหน่ง 39 (มีรูป 39), ใบเบิก 2 ใบ 3 รายการ`
5. **Deploy → New deployment** → ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

ทุกครั้งที่แก้ Code.gs ต้อง **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
URL จะเหมือนเดิม

## ขั้นที่ 2: ตั้งแชร์โฟลเดอร์รูป

แอปแสดงรูปผ่านลิงก์ของ Google Drive จึงต้องแชร์โฟลเดอร์รูปแบบดูได้
คลิกขวาโฟลเดอร์ `DATA_Part_Images` และ `Location_Images` → Share → General access →
**Anyone with the link** (Viewer) ถ้าไม่แชร์ แอปใช้งานได้ปกติ แต่รูปจะไม่ขึ้น

## ขั้นที่ 3: เอาเว็บขึ้น GitHub Pages

1. แก้ `config.js` ใส่ Web app URL จากขั้นที่ 1 แทน `PASTE_WEB_APP_URL_HERE`
2. สร้าง repository ใหม่ใน GitHub เช่น `spare-parts` (แยกจาก repo ระบบตรวจทรัพย์สิน)
3. อัปโหลดไฟล์ทั้งหมดยกเว้น `Code.gs` และ `README.md` (อัปโหลดด้วยก็ได้ ไม่มีความลับในนั้น)
   ต้องมีโฟลเดอร์ `icons/` และ `vendor/` ด้วย
4. Settings → Pages → Deploy from a branch → main / root → Save
5. รอสักครู่ จะได้ URL เช่น `https://<ชื่อผู้ใช้>.github.io/spare-parts/`

เปิด URL บนมือถือ ใส่รหัสทีมและชื่อ แล้วกด "เพิ่มไปยังหน้าจอหลัก" เพื่อใช้เหมือนแอป

## ก่อนเลิกใช้ AppSheet

- ใบเบิก **SR26-000112** ในชีทยังเป็น Draft แต่จำนวนใน DATA_Part ถูกหักไปแล้วด้วยมือ
  (Remark ของ B0000812/B0000813 เขียนว่าเบิกแล้ว) ให้แก้ Status ในชีทเป็น `Approved` เอง
  ไม่อย่างนั้นถ้ากดอนุมัติในแอป จะหักซ้ำ (ตอนนี้แอปจะไม่ยอม เพราะคงคลังเป็น 0)
- ชีท `External_Part` และ `Contact_No` แอปยังไม่ได้ใช้ ข้อมูลอยู่ในชีทเหมือนเดิม
- ระหว่างที่ AppSheet ยังเปิดอยู่ อย่าให้สองระบบแก้ใบเบิกเดียวกันพร้อมกัน

## แก้ไขภายหลัง

- เปลี่ยนชื่อแอป คำแสดงสถานะ หรือตัวนำเลขที่ใบเบิก: แก้ `config.js`
- ไม่ต้องการให้อนุมัติแล้วหักคลังอัตโนมัติ: ใน Code.gs ตั้ง `DEDUCT_ON_APPROVE: false`
- ค่าเริ่มต้นตอนเพิ่มอะไหล่ใหม่ (คลัง หน่วยงาน Type): แก้ `DEFAULTS` ใน Code.gs
- แก้ไฟล์บน GitHub แล้วมือถือไม่อัปเดต: เปลี่ยน `VERSION` ใน `sw.js` เช่น `sp-v2`

## ข้อจำกัด

- การบันทึกทุกอย่างต้องต่ออินเทอร์เน็ต ถ้าออฟไลน์ยังเปิดดูข้อมูลล่าสุดที่โหลดไว้ได้
- ทุกคนที่มีรหัสทีมทำได้ทุกอย่าง รวมถึงอนุมัติใบเบิก ถ้าต้องการแยกสิทธิ์ผู้อนุมัติ แจ้งได้
